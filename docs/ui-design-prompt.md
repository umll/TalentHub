# TalentHub 页面设计提示词（用于 AI 设计工具）

> 使用方式：整段复制给 AI 设计/绘图工具。若工具支持多轮，可先发「全局部分」，再逐页发送。

---

## 提示词正文

你是一名资深 B 端产品视觉设计师。请为「TalentHub 培训课程抢课系统」设计一套高保真网页界面。这是企业内部人力资源系统中的培训报名模块，核心场景是员工在限定时间内抢报名额有限的培训课程（类秒杀，但面向内部员工，气质应当克制专业，不要电商促销感）。

### 技术与设计约束（必须遵守，设计稿要能落地）

- 前端实现为 Vue 3 + **Arco Design Vue** 组件库，设计必须基于 Arco Design 设计语言：主色 arcoblue（#165DFF），中性色灰阶，圆角 4–8px，浅色主题，字体优先 PingFang SC / 微软雅黑。
- 所有控件从 Arco 现有组件出发做视觉升级（Table、Card、Tag、Button、Modal、Tabs、Select、Statistic、Progress、Steps、Result、Empty），不要发明组件库无法实现的复杂控件。
- 桌面端优先，画板宽度 1440px，内容区最大宽度约 1080–1200px 居中。
- 状态语义色固定：报名中=绿色、已结束=红色、未开始=灰色、已取消=橙色；剩余名额充足=蓝、紧张(<30%)=橙、售罄=红。

### 全局框架

- 顶部导航栏（高 60px，白底、底部细分割线）：左侧产品名「TalentHub 抢课演示」+ 可选 logo 占位；中部水平菜单：课程列表 / 我的报名 / 管理端（管理端仅管理员可见）；右侧「演示用户切换器」下拉（显示当前用户名，管理员带标识徽标）。
- 页面背景浅灰（--color-fill-2），内容卡片白底微投影。
- 整体风格关键词：**企业级、清爽、信息层级分明、留白充足、克制的强调色**；抢课的「紧迫感」只通过倒计时数字与名额进度视觉表达，不用促销弹窗和大红大紫。

### 页面一：课程列表（核心页面，重点设计）

功能：展示全部培训课程，用户在此完成抢课。
- 现状是纯表格，请升级为**课程卡片流**（每行 2–3 张卡片）或「顶部数据概览 + 卡片列表」的组合，信息密度与美观兼顾。
- 每张课程卡片包含：课程名称（可点击进详情）、报名时间段、状态标签、**剩余名额可视化**（如 12/20 进度条或环形，颜色随余量变化）、主操作按钮。
- 按钮状态要完整设计：「抢课」（主色实心，醒目）/「已抢完」（禁用灰）/「已报名 → 取消报名」（次级按钮或含对勾的成功态）/ 未开始时显示**倒计时**（mm:ss，等宽数字，橙色，卡片上位置醒目）。
- 页面附带一条轻量提示：数据每 5 秒自动刷新（可设计为右上角刷新按钮 + 静默刷新的小圆点动效）。
- 设计三种卡片状态示例：报名中（余量充足）、报名中（即将售罄，余 2/20）、未开始（带倒计时）。

### 页面二：课程详情

功能：单课程完整信息与报名操作。
- 上部课程信息区：课程名大标题、状态标签、报名起止时间、剩余名额大号可视化（推荐 Statistic 数字 + 进度条组合）。
- 下部操作区：与列表页一致的按钮状态体系；未开始时展示大号倒计时。
- 预留一段课程简介占位文本区域。

### 页面三：我的报名

功能：当前用户的报名记录与取消操作。
- 表格或时间线形式：课程名、状态（已报名=绿 Tag / 已取消=灰 Tag）、报名时间、取消时间、操作列（仅"课程仍在报名中且未取消"时显示「取消报名」，弱化为文字按钮或次级按钮，配确认气泡）。
- 设计空状态：还没有报名记录时的 Empty 插画 + 「去抢课」引导按钮。

### 页面四：管理端

功能：课程管理与库存对账审计，Tabs 双页签。
- 页签 1「课程管理」：工具栏（新建课程主按钮 + 刷新）+ 课程表格（ID、课程、名额徽标、报名时间段、状态、操作：编辑/预热）。「预热」是把库存加载进 Redis 的技术动作，按钮请配 tooltip 说明。
- 「新建/编辑课程」弹窗：表单三项——课程名称、总名额（数字输入）、报名时间段（带时间的范围选择器），设计好校验错误态。
- 页签 2「对账记录」：审计表格（课程、Redis 库存、DB 库存、修正动作、时间）。修正动作用彩色 Tag 区分：FIX_REDIS_HIGH（橙）、FIX_REDIS_LOW（蓝）、DB_SELF_INCONSISTENT（红）。设计「全部一致、暂无修正记录」的正向空状态。

### 关键反馈态（全局）

- 抢课结果反馈用 Arco Message 轻提示：成功（报名成功）/ 信息（您已报名该课程）/ 警告（名额已满、当前人数过多请稍后重试）。请设计这几条 Message 的样式示例。
- 按钮点击后立即进入 loading 态（防连点），设计 loading 中的按钮形态。

### 交付要求

每个页面输出 1440px 宽高保真视觉稿；课程卡片单独放大展示三种状态；标注主色、状态色、圆角、间距基准（8px 栅格）；整套页面保持同一设计语言。
